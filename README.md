A simple and responsive Weather App built using HTML, CSS, and JavaScript, integrated with the OpenWeatherMap API to fetch real-time weather data based on city input.
🔍 Features
🌎 Search weather by city name
🌡️ Displays temperature, humidity, wind speed, and weather description
📷 Dynamic weather icons based on conditions
📱 Responsive design for all screen sizes
🚀 Fast and lightweight – no frameworks used

🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
OpenWeatherMap API


How to run? 
1. Open index.html in your browser (e.g., in VS Code)
2. Enter a city name and get real-time weather info!
⚠️ Make sure to replace "YOUR_API_KEY" in the JavaScript file with your actual OpenWeatherMap API key.
